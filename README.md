# MERN Chat Application (Socket.IO) — WhatsApp/Telegram style

## Features
- React (Vite) frontend + Bootstrap 5 responsive UI
- Dark/Light mode toggle
- JWT authentication (bcrypt password hashing)
- Protected routes (React Router)
- One-to-one real-time chat using Socket.IO
- Online/offline presence
- Typing indicator
- Delivery status + read receipts
- User search + chat sidebar
- Profile view/edit + profile image upload
- Toast notifications + loading spinners

## Tech Stack
- **Client:** React, Vite, Bootstrap 5, Axios, React Router, Socket.IO client
- **Server:** Node.js, Express, MongoDB (Mongoose), JWT, bcrypt, Socket.IO, multer
